# OmniPlayer

OmniPlayer is a high-performance, all-in-one multimedia application designed for seamless local media playback and internet radio streaming. Built with a focus on efficiency and user experience, OmniPlayer allows you to manage your music and video library while staying connected to the world of radio.

## 🚀 Features

- **Local Media Playback:** Easily access and play your favorite MP3 and video files stored directly on your device.
- **Internet Radio:** Integrated radio streaming service to discover and listen to stations from around the globe.
- **Optimized Performance:** Designed to be lightweight and fast, ensuring smooth playback without consuming unnecessary system resources.
- **User-Centric Design:** Clean and intuitive interface for an effortless listening and viewing experience.
- **Privacy First:** We value your data. No personal data is harvested or uploaded to external servers.
